# 🍽️ MAA – Meal As Asked

An AI-driven food ordering application where users can chat with an AI assistant named **MAA** instead of browsing menus. MAA understands natural language requests and finds the closest available food matching the user's preferences.

## 🚀 Tech Stack

### Frontend
- React Native
- React.js
- TypeScript
- Material UI (MUI)
- HTML5
- CSS3
- JavaScript (ES6+)

### Backend
- Node.js
- REST APIs

### Artificial Intelligence
- OpenAI API
- Natural Language Processing (NLP)

- GitHub

- npm

### Platform
