# 🍽️ MAA – Meal As Asked (Client)

MAA (Meal As Asked) is an AI-driven food ordering application where users interact with an AI assistant named **MAA** instead of browsing traditional menus. The assistant understands natural language requests, identifies the user's food preferences, and helps discover nearby restaurants offering matching meals.

> **🚧 Project Status:** This client application is currently under active development. New features, UI improvements, and AI capabilities are being implemented continuously.

---

## ✨ Features

- 🤖 AI-powered conversational food ordering
- 💬 Natural language interaction with MAA
- 🍽️ Personalized meal recommendations
- 📍 Location-aware restaurant discovery
- 📱 Modern and responsive mobile interface
- 🔄 Real-time communication with backend APIs
